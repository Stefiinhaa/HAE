==============================================================================
GUIA DE IMPLANTAÇÃO E HOSPEDAGEM - SISTEMA HAE NA LOCAWEB
==============================================================================

Este documento contém todas as instruções necessárias para subir o Sistema HAE
na Hospedagem de Sites da Locaweb com pleno funcionamento e segurança máxima.

------------------------------------------------------------------------------
1. BANCO DE DADOS (MYSQL)
------------------------------------------------------------------------------
1.1. No Painel da Locaweb, vá em "Banco de Dados" > "Criar Banco de Dados MySQL".
     - Guarde o Nome do Banco, Usuário, Senha e o Host do Servidor.
1.2. ATENÇÃO CRUCIAL (Particularidade da Locaweb):
     - Na Locaweb, o host do banco de dados NUNCA é "localhost".
     - A Locaweb fornece um host específico, por exemplo:
       mysql.seudominio.com.br  ou  179.188.16.x
1.3. Importação da Estrutura:
     - Acesse o phpMyAdmin da Locaweb pelo painel.
     - Selecione o banco criado e clique na aba "Importar".
     - Selecione o arquivo: banco_estrutura.sql (já incluído na pasta).
     - Caso queira subir também os dados locais de teste/homologação existentes,
       utilize o arquivo sistema_hae.sql.

------------------------------------------------------------------------------
2. ARQUIVO DE CONEXÃO COM O BANCO (config/conexao.php)
------------------------------------------------------------------------------
Abra o arquivo "config/conexao.php" e ajuste as credenciais criadas no passo 1:

   $host = 'mysql.seudominio.com.br'; // HOST FORNECIDO PELA LOCAWEB (NÃO localhost)
   $dbname = 'nome_do_banco_criado';
   $username = 'usuario_criado';
   $password = 'senha_do_banco';

------------------------------------------------------------------------------
3. VERSÃO DO PHP E CONFIGURAÇÃO
------------------------------------------------------------------------------
No Painel da Locaweb (Hospedagem > Gerenciar > Configuração do PHP):
- Selecionar versão: PHP 8.2 (ou superior).
- Assegurar que as seguintes extensões padrão estejam ativas:
  * pdo_mysql
  * curl
  * mbstring
  * fileinfo
  * gd
  * openssl
  (Na Locaweb essas extensões já vêm habilitadas por padrão no PHP 8.2).

------------------------------------------------------------------------------
4. CERTIFICADO DIGITAL SSL (HTTPS)
------------------------------------------------------------------------------
- No painel da Locaweb, ative o certificado SSL Gratuito (Let's Encrypt).
- O sistema exige HTTPS para o funcionamento de:
  * Service Workers (Notificações Push / PWA)
  * Proteção de cookies de sessão segura (SameSite e Secure)
  * Criptografia de senhas e dados acadêmicos

------------------------------------------------------------------------------
5. PERMISSÕES DE ARQUIVOS E DIRETÓRIOS (LINUX / CHMOD)
------------------------------------------------------------------------------
Via Gerenciador de Arquivos do Painel ou via FTP (FileZilla):
- Pasta "uploads/" e subpastas (ex: "uploads/assinaturas/"):
  Definir permissão de escrita: CHMOD 755 ou 775.
- Arquivo "ultimo_cron.txt" na raiz:
  Definir permissão de escrita: CHMOD 664 ou 666 (armazena data do último disparo).

------------------------------------------------------------------------------
6. ARQUIVOS OCULTOS DE SEGURANÇA (.htaccess)
------------------------------------------------------------------------------
O sistema conta com proteção de diretórios e bloqueio de arquivos confidenciais
via arquivos .htaccess:
- .htaccess (na raiz do sistema)
- config/.htaccess
- uploads/.htaccess
- vendor/.htaccess

AO EXTRAIR O ZIP NA PASTA DE HOSPEDAGEM (ex: public_html):
Certifique-se de que os arquivos que começam com ponto (".htaccess") foram
extraídos. No Linux ou em alguns clientes FTP, arquivos iniciados por ponto
podem ser ocultados na visualização, mas devem estar presentes no servidor.

------------------------------------------------------------------------------
7. TAREFA AGENDADA / CRON JOB (Notificações de Relatórios)
------------------------------------------------------------------------------
O sistema possui rotina diária de verificação de relatórios atrasados
(executada entre os dias 1 e 11 de cada mês).

No Painel da Locaweb, acesse "Tarefas Agendadas" / "Cron":
- Periodicidade: Diária (sugestão: 08:00 da manhã).
- Tipo: Chamada de URL via curl ou wget.
- Comando:
  curl -s "https://seudominio.com.br/cron_notificacoes.php?token=HaeFatec2026" > /dev/null 2>&1

* Se você alterar o token em config/segredos.php (CRON_TOKEN), atualize a URL acima.

------------------------------------------------------------------------------
8. CONFIGURAÇÕES ADICIONAIS (config/segredos.php)
------------------------------------------------------------------------------
Todas as credenciais sensíveis (SMTP de e-mail, tokens) ficam centralizadas
no arquivo "config/segredos.php":
- Caso use e-mail corporativo da Locaweb (ex: contato@seudominio.com.br):
  Altere SMTP_HOST para 'email-ssl.com.br', coloque o usuário e a senha.
- Caso continue usando Gmail institucional, mantenha os dados atuais.
- Se o domínio for configurado, a constante APP_URL pode receber a URL
  (ex: 'https://sistemahae.com.br') ou ser deixada vazia '', pois o sistema
  detecta o domínio automaticamente.
