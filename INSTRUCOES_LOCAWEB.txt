==============================================================================
GUIA DE IMPLANTACAO E HOSPEDAGEM - SISTEMA HAE NA LOCAWEB
==============================================================================

Este documento contem as instrucoes para colocar o Sistema HAE no ar na
Hospedagem de Sites da Locaweb (Linux + Apache + PHP).

------------------------------------------------------------------------------
1. BANCO DE DADOS (MYSQL)
------------------------------------------------------------------------------
1.1. No Painel da Locaweb, va em "Banco de Dados" > "Criar Banco de Dados MySQL".
     Guarde: nome do banco, usuario, senha e o HOST do servidor.
1.2. ATENCAO: na Locaweb o host do banco NUNCA e "localhost".
     Exemplo de host: mysql.seudominio.com.br  (ou um IP fornecido no painel).
1.3. No phpMyAdmin da Locaweb: selecione o banco > aba "Importar" >
     escolha o arquivo banco_estrutura.sql (estrutura limpa, sem usuarios).
1.4. Se for necessario migrar os dados atuais (usuarios, projetos), o
     responsavel pelo sistema entregara um arquivo de backup SEPARADO (.sql),
     fora deste ZIP. Importe-o da mesma forma e NUNCA o envie para dentro da
     pasta publica do site (public_html).

------------------------------------------------------------------------------
2. CONEXAO COM O BANCO (config/conexao.php)
------------------------------------------------------------------------------
Abra "config/conexao.php" e preencha com os dados criados no passo 1:

   $host   -> o host da Locaweb (NAO use localhost)
   $dbname -> nome do banco criado
   $user   -> usuario do banco
   $pass   -> senha do banco

------------------------------------------------------------------------------
3. VERSAO DO PHP
------------------------------------------------------------------------------
No Painel da Locaweb (Hospedagem > Configuracao do PHP):
- Selecione PHP 8.2 (ou superior).
- Extensoes necessarias (normalmente ja ativas): pdo_mysql, curl, mbstring,
  fileinfo, gd, openssl.

------------------------------------------------------------------------------
4. CERTIFICADO SSL (HTTPS) - OBRIGATORIO
------------------------------------------------------------------------------
- Ative o SSL gratuito (Let's Encrypt) no painel e, se houver, a opcao de
  redirecionar HTTP para HTTPS.
- O HTTPS e necessario para notificacoes push, cookies de sessao seguros e
  para proteger as senhas durante o login.

------------------------------------------------------------------------------
5. PERMISSOES (CHMOD)
------------------------------------------------------------------------------
- Pasta "uploads/" e "uploads/assinaturas/": permissao de escrita (755 ou 775).
- Arquivo "ultimo_cron.txt" (raiz): permissao de escrita (664 ou 666).
- NAO use 777 em nenhuma pasta.

------------------------------------------------------------------------------
6. ARQUIVOS .htaccess (PROTECAO) - NAO APAGAR
------------------------------------------------------------------------------
Arquivos que comecam com ponto (.htaccess) ficam ocultos em alguns programas.
Confirme que existem apos extrair o ZIP:
   .htaccess              (raiz)
   config/.htaccess
   uploads/.htaccess
   vendor/.htaccess
Eles bloqueiam o acesso externo a credenciais, banco, logs e codigo de apoio.

Se o site der "Erro 500" logo apos enviar os arquivos, abra o .htaccess da
raiz e comente (coloque # na frente) a linha "Options -Indexes"; algumas
hospedagens nao permitem essa diretiva. O restante da protecao continua ativo.

------------------------------------------------------------------------------
7. TAREFA AGENDADA (CRON) - COBRANCA DE RELATORIOS
------------------------------------------------------------------------------
O sistema verifica diariamente relatorios atrasados (dias 1 a 11 de cada mes).
Agende uma chamada diaria (ex.: 08:00), pelo painel da Locaweb ("Tarefas
Agendadas") ou pelo site cron-job.org, para a URL:

   https://SEU-DOMINIO/cron_notificacoes.php?token=VALOR_DO_CRON_TOKEN

O VALOR_DO_CRON_TOKEN e o que esta em config/segredos.php (linha CRON_TOKEN).
Se alterar o token no arquivo, altere tambem na URL agendada.
Comando para o agendador da Locaweb:
   curl -s "https://SEU-DOMINIO/cron_notificacoes.php?token=VALOR_DO_CRON_TOKEN" > /dev/null 2>&1

------------------------------------------------------------------------------
8. CONFIGURACOES (config/segredos.php)
------------------------------------------------------------------------------
- SMTP_*  : e-mail usado para enviar avisos e recuperacao de senha.
            (Gmail com senha de app, ou e-mail da propria Locaweb.)
- APP_URL : RECOMENDADO preencher com o endereco final, por exemplo
            'https://sistemahae.seudominio.com.br'  (sem barra no final).
            Garante que os links nos e-mails e notificacoes apontem sempre
            para o endereco oficial.

------------------------------------------------------------------------------
9. TESTE FINAL (5 minutos)
------------------------------------------------------------------------------
1. Abra https://SEU-DOMINIO/config/conexao.php  -> deve mostrar "Acesso
   restrito" ou erro 403. (Se mostrar qualquer outra coisa, os .htaccess
   nao foram enviados.)
2. Abra https://SEU-DOMINIO/banco_estrutura.sql -> deve dar 403.
3. Faca login, abra o painel e envie uma assinatura de teste (perfil).
4. Teste "Esqueci a senha" e confira se o e-mail chega.
5. Entre com 2 computadores/celulares diferentes e erre a senha 5 vezes em UM
   deles: o outro NAO pode ser bloqueado. Se for bloqueado, a hospedagem usa
   proxy: avise o desenvolvedor (ajuste HAE_IP_CABECALHO em
   config/seguranca.php).

------------------------------------------------------------------------------
Fim. O sistema esta pronto para producao.
